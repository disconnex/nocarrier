# The No Carrier BBS

The homepage of **##nocarrier** on Libera.Chat, a 1996-style bulletin board
that lives in an IRC channel: retro computing, BBS door games, trivia, a
weekly gold jackpot, and people chatting from real Windows 95 machines.

**Visit:** https://disconnex.github.io/nocarrier/
**Join:** https://web.libera.chat/##nocarrier, or any IRC client:
`irc.libera.chat` port 6697 (SSL), channel `##nocarrier`.

The pages here are generated every hour by SysopBot, the channel's Eggdrop
bot, on a Raspberry Pi, and pushed automatically. They show the jackpot,
upcoming events, the door game's top heroes and channel statistics (numbers
only: no chat lines are published). Please don't send pull requests for the
HTML; it's overwritten every hour. Say hi in the channel instead.
